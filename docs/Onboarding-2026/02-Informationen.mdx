# Informationen
Grundsätzlich gilt: **Alles, was auf _Classrooms_ steht, sollten Sie lesen**. Um Ihnen das Lesen zu erleichtern, sind besonders wichtige Informationen aber oft nochmal spezifisch hervorgehoben. Entweder wird das Wort oder der Satz **fett** geschrieben, oder es wird eine entsprechende _«Kachel»_ verwendet.

Folgende Kacheln werden Sie regelmässig sehen:

:::aufgabe[Aufgabe]
<TaskState id="0a0382ec-e4ef-4b03-9660-c3e33b74e1e7" />
Das ist eine Aufgabe – diese Kachel kennen Sie bereits. Sie können diese gleich als erledigt markieren – mehr gibt es hier nicht zu tun 😉.
:::

:::info[Information / Tipp]
Das ist eine Zusatzinformation oder ein Tipp. Diese Kachel enthält wichtige Informationen, die Sie beachten sollten.
:::

:::warning[Warnung]
Das ist eine Warnung. Informationen in solchen Kacheln müssen Sie besonders sorgfältig lesen, da sonst möglicherweise etwas schiefgehen könnte.
:::

:::danger[Gefahr]
Bei einer Gefahr-Kachel wird es ernst! Lesen Sie die Informationen sehr sorgfältig durch und befolgen Sie die Anweisungen ganz genau.
:::

:::insight[Erkenntnis]
Erkenntnis-Kacheln enthalten Schlüsselergebnisse aus dem Lernstoff. Sie fassen zentrale Informationen zusammen oder ziehen wichtige Schlussfolgerungen.
:::

:::definition[Definition]
Ab und zu sehen Sie solche Definitions-Kacheln. Sie enthalten wichtige Begriffe, die Sie kennen sollten.
:::

## Seite gelesen?
Haben Sie **alles gelesen** und die **obige Aufgabe als erledigt markiert**? Super!

Wie Sie gemerkt haben, gab es auf dieser Seite keine (echten…) Aufgaben zu erledigen, dafür umso wichtiger Informationen zu lesen. Deshalb finden Sie am Ende dieser und ähnlicher Seiten einen **Slider**, mit dem Sie bestätigen können, dass Sie die Seite gelesen haben. **Der Fortschritt dieser Seite wird erst dann auf grün gesetzt, wenn Sie dies erledigt haben**.

Um sicherzustellen, dass Sie sich die nötige Zeit zum Lesen genommen haben, kann dieser Slider **erst nach Ablauf eines Countdowns** (in diesem Fall 50 Sekunden) bewegt werden.

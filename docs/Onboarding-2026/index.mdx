# Willkommen 👋
Willkommen auf _Classrooms_! Auf dieser Plattform finden Sie alle Informationen und Übungen für den Informatikunterricht.

Auf der <ClassStartPage /> finden Sie den Terminplan, wichtige Abmachungen und weiteren organisatorischen Informationen. Zu den inhaltlichen Themen gelangen Sie links über die Navigationsleiste. Das Thema, das wir gerade behandeln, ist immer zuunterst aufgelistet.

:::aufgabe[Vorbereitung auf den Unterricht]
<TaskState id="c3f418f5-2289-4771-941a-39d9d42ac744" />
Damit Sie zu Beginn der Informatiklektionen keine wertvolle Zeit verlieren, wird erwartet, dass Sie **Classrooms beim Läuten bereits geöffnet haben und eingeloggt sind**.

Speichern Sie sich die <ClassStartPage /> deshalb gleich als Lesezeichen ab. **Gehen Sie dazu wie folgt vor:**

<Steps>
1. Suchen Sie bei Bedarf nach einer Anleitung, wie man in Ihrem Browser (Edge, Safari, Google Chrome, Firefox, …) ein Lesezeichen erstellt. Geben Sie dazu bei Google «Lesezeichen erstellen in [Ihr Browser]» ein.
2. Öffnen Sie die <ClassStartPage /> in einem neuen Tab (am einfachsten: Rechtsklick auf diesen Link und «In neuem Tab öffnen» auswählen).
3. Wechseln Sie zum Tab mit der Klassen-Startseite. Kontrollieren Sie nochmal, ob am oberen Seitenrand «<ClassStartPageTitle />» steht. Erstellen Sie dort dann ein Lesezeichen **in der Lesezeichen-Leiste**.
4. Überprüfen Sie das neue Lesezeichen: Öffnen Sie einen neuen Tab, gehen Sie zur Lesezeichen-Leiste und klicken Sie auf das Classrooms-Lesezeichen. Falls die Lesezeichen-Leiste nicht sichtbar ist, suchen Sie online nach einer Anleitung, wie man die Lesezeichen-Leiste in Ihrem Browser einblendet.
</Steps>
:::

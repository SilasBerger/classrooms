# Programmieren 2

## Lernziele
:::info[Prüfungsstoff]
1. Repetition
   1. Sämtliche Python-bezogenen Lernziele aus dem ersten Programmierblock (Turtle, Schleifen, Variablen, Ein- und Ausgabe, Verzweigungen / Booleans, Zufall, Bugs; keine Struktogramme, keine Algorithmen-Theorie).
   2. Sie beherrschen die Verzweigung in Python, inkl. `if`, `elif` und `else`, sowie die damit verbundenen Vergleichsoperatoren und den Datentyp `bool`. Logische Ausdrücke (z.B. `True and (False or True)`) können Sie auch von Hand auswerten.
   3. Sie beherrschen die arithmetischen Grundoperationen in Python, inkl. Ganzzahldivision (Division mit Rest), Modulo und Potenzierung, mit und ohne Klammern, sowohl in Code als auch von Hand.
2. Listen
   1. Sie können eine Liste mit Zahlen und/oder Strings definieren.
   2. Sie können auf beliebige Elemente einer Liste (auch das letzte Element) zugreifen und diese z.B. in der Kommandozeile ausgeben.
   3. Sie können die Länge einer Liste bestimmen.
   4. Sie können eine Liste mit einer for-Schleife durchlaufen und die Elemente z.B. in der Kommandozeile ausgeben.
   5. Sie können eine Liste mit einer for-Schleife über die Indizes durchlaufen (`for i in range(len(liste))`) und dabei auch auf benachbarte Elemente (z.B. `liste[i - 1]`) zugreifen.
   6. Sie können einer Liste Elemente hinzufügen (`.append()`).
   7. Sie können den Wert eines Elements in einer Liste ändern.
3. Funktionen
    1. Sie können Code in eine Funktion auslagern und diese Funktion aufrufen.
    2. Sie können Funktionen definieren, die einen oder mehrere Parameter entgegennehmen.
    3. Sie können Funktionen definieren, die einen Wert zurückgeben.
    4. Sie können eine Funktion aufrufen und ihr Argumente übergeben.
    5. Sie können den Rückgabewert einer Funktion in einer Variablen speichern.
4. Mini Advent of Code
    1. Sie können für ein komplexes algorithmisches Problem mit vorgegebenen Input-Daten, einer Beschreibung der Input-Daten und einer Beschreibung der erwarteten Lösung ein Python-Programm schreiben, das die Lösung berechnet.
:::

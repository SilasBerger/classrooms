# Listen
Bisher haben wir in einer Variable immer genau **einen** Wert gespeichert, z.B. `note = 5`. Was aber, wenn wir alle Noten einer Prüfung oder die Temperaturen eines ganzen Monats speichern wollen? Für jeden Wert eine eigene Variable (`note_1`, `note_2`, `note_3`, …) wäre sehr mühsam. Vielleicht erinnern Sie sich an die Aufgabe «Balkendiagramm» in der Repetition: Dort brauchte es für jeden Tag eine eigene Variable und fast denselben Code mehrmals.

Dafür gibt es in Python **Listen**: Eine Liste speichert **mehrere Werte** unter einem **einzigen Namen**.

## Listen erstellen
:::insight[Liste erstellen]
Eine Liste schreiben wir mit eckigen Klammern `[` und `]`. Die einzelnen Werte (die **Elemente** der Liste) trennen wir mit Kommas:

```py live_py slim
noten = [5, 4.5, 6, 4, 5.5]
print(noten)
```

Eine Liste kann auch Strings enthalten. Oder sie kann (vorerst) ganz leer sein:

```py live_py slim
namen = ['Anna', 'Ben', 'Chiara']
einkaufsliste = []

print(namen)
print(einkaufsliste)
```
:::

## Auf Elemente zugreifen
::::insight[Index]
Die Elemente einer Liste sind durchnummeriert. Die Nummer eines Elements heisst **Index**. Mit `liste[index]` greifen wir auf ein einzelnes Element zu.

**Achtung:** Das erste Element hat den Index `0`, nicht `1`!

| Index   | `0` | `1`   | `2` | `3` | `4`   |
|---------|-----|-------|-----|-----|-------|
| Element | `5` | `4.5` | `6` | `4` | `5.5` |

```py live_py slim
noten = [5, 4.5, 6, 4, 5.5]
print(noten[0])
print(noten[3])
```

Mit einem **negativen Index** zählen wir von hinten: `noten[-1]` ist das letzte Element, `noten[-2]` das zweitletzte usw.

```py live_py slim
noten = [5, 4.5, 6, 4, 5.5]
print(noten[-1])
```

Der Index kann auch in einer Variable stehen:

```py live_py slim
noten = [5, 4.5, 6, 4, 5.5]
x = 2
print(noten[x])
```

Gibt es zu einem Index kein Element, bricht das Programm mit einem `IndexError` ab:

```py live_py slim
noten = [5, 4.5, 6, 4, 5.5]
print(noten[5])
```

## Länge einer Liste
:::insight[`len()`]
Mit `len(liste)` erhalten wir die **Länge** einer Liste, also die Anzahl Elemente:

```py live_py slim
noten = [5, 4.5, 6, 4, 5.5]
anzahl = len(noten)
print(f'Es gibt {anzahl} Noten.')
```

Weil der Index bei `0` beginnt, hat das letzte Element immer den Index `len(liste) - 1`. Bei unseren 5 Noten ist das der Index `4`.
:::

## Elemente ändern und hinzufügen
:::insight[Element ändern]
Wie bei einer Variable können wir einem Element einer Liste einen neuen Wert zuweisen:

```py live_py slim
noten = [5, 4.5, 6, 4, 5.5]
noten[1] = 5
print(noten)
```
:::

:::insight[Element hinzufügen: `append()`]
Mit `liste.append(wert)` hängen wir ein neues Element **am Ende** der Liste an. Die Liste wird dadurch um ein Element länger:

```py live_py slim
noten = [5, 4.5, 6, 4, 5.5]
noten.append(6)
print(noten)
print(len(noten))
```
:::

## Listen durchlaufen
:::insight[`for`-Schleife über eine Liste]
Mit einer `for`-Schleife können wir alle Elemente einer Liste der Reihe nach durchlaufen. Die Schleifenvariable (hier `note`) enthält bei jedem Durchlauf das nächste Element:

```py live_py slim
noten = [5, 4.5, 6, 4, 5.5]

for note in noten:
    print(note)
```

Das funktioniert genau wie `for i in range(5)`. Nur nimmt die Schleifenvariable hier nicht die Werte `0`, `1`, `2`, … an, sondern nacheinander die Elemente der Liste.

Zusammen mit einer Variable, die vor der Schleife bei `0` startet, können wir so z.B. die Summe aller Elemente berechnen:

```py live_py slim
noten = [5, 4.5, 6, 4, 5.5]

summe = 0
for note in noten:
    summe = summe + note

print(f'Summe: {summe}')
```
:::

## Listen über die Indizes durchlaufen
:::insight[`for i in range(len(liste))`]
Manchmal brauchen wir in der Schleife nicht nur das Element, sondern auch seinen **Index**. Dann lassen wir die Schleife mit `range(len(liste))` über alle Indizes laufen und greifen mit `liste[i]` auf das Element zu:

```py live_py slim
namen = ['Anna', 'Ben', 'Chiara']

for i in range(len(namen)):
    print(f'Index {i}: {namen[i]}')
```

Bei drei Namen ist `len(namen)` gleich `3`. Die Schleife läuft also wie `for i in range(3)` über die Indizes `0`, `1` und `2`.

Über den Index können wir die Elemente in der Schleife auch **ändern**:

```py live_py slim
preise = [4, 10, 7]

for i in range(len(preise)):
    preise[i] = preise[i] * 2

print(preise)
```
:::

:::insight[Benachbarte Elemente]
Mit dem Index können wir auch auf **benachbarte** Elemente zugreifen: `liste[i - 1]` ist das Element **vor** `liste[i]`.

Beim ersten Element (Index `0`) gibt es aber kein Element davor. Wir lassen die Schleife deshalb erst beim Index `1` beginnen. Dafür geben wir `range()` zwei Werte: `range(1, len(liste))` beginnt bei `1` und hört (wie immer) **vor** `len(liste)` auf.

```py live_py slim
punkte = [10, 14, 12, 19]

for i in range(1, len(punkte)):
    differenz = punkte[i] - punkte[i - 1]
    print(f'Von Index {i - 1} zu Index {i}: {differenz}')
```
:::

# 🔬 Experiment RSA
In diesem Experiment werden Sie in der Klasse geheime Nachrichten austauschen – und zwar über einen «öffentlichen» Kanal.

:::insight[Wie funktioniert RSA?]
[Hier](https://www.cryptool.org/de/cto/rsa-step-by-step/) können Sie sich die Funktionsweise des RSA-Verfahrens Schritt für Schritt ansehen.
:::

## Phase 1
<Steps>
1. Öffnen Sie dieses [RSA Tool](https://www.devglan.com/online-tools/rsa-encryption-decryption) – wir werden es im Verlauf dieses Experiments noch öfter verwenden.
2. Klicken Sie auf __Create RSA Key Pair__ (mit dem voreingestellten Wert `2048 bits`).
4. Kopieren Sie die beiden generierten Werte (also den Public und den Private Key) ins Notizen-Textfeld oben. **Sie brauchen diese beiden Keys für den Rest dieses Experiments und können Sie nicht ändern oder wiederherstellen.**
5. Kopieren Sie Ihren **Public** Key in die erste Tabelle im Word-Dokument (Abschnitt «Public Keys») und schreiben Sie Ihren Namen dazu.
</Steps>
</Restricted>

<Restricted id="df9d4984-761a-4354-ad08-286c69b8447d">
## Phase 2
In dieser Phase versenden Sie zwei verschlüsselte Nachrichten über den «öffentlichen» Kanal.

<Steps>
1. Schauen Sie sich im Word-Dokument nochmal die Tabelle mit den Public Keys an. Notieren Sie sich die Namen der **beiden Personen, die direkt ober und unter Ihnen** stehen. Falls Sie zuoberst oder zuunterst stehen, fangen Sie ganz unten resp. oben wieder an. Diese beiden Personen sind **Ihre Empfänger:innen**.  
2. Wählen Sie eine der beiden Personen aus und verfassen Sie oben im Notizen-Textfeld für diese Person eine kurze Nachricht (max. 190 Zeichen, bitte nichts Privates). Sie werden diese Nachricht in den nächsten Schritten verschlüsseln.
3. Öffnen Sie wieder das [RSA Tool](https://www.devglan.com/online-tools/rsa-encryption-decryption) und gehen Sie zum Bereich __RSA Encryption__. Wählen Sie `Key type: Public key` and `Padding: OAEP SHA-256` (sollte bereits voreingestellt sein).
4. Kopieren Sie Ihre Nachricht in das Feld __Plain text__.
   :::danger[Textlänge]
   **Achtung:** Der Text darf nicht länger als 190 bytes sein.
   :::
5. Suchen Sie im Word-Dokument den Public Key des/der Empfänger:in und kopieren Sie diesen in das Feld __Public / private key__ im RSA Tool. Klicken Sie dann auf __Encrypt__.
6. Kopieren Sie die verschlüsselte Nachricht aus dem Feld __Encrypted output (Base64)__ ins Word-Dokument (Tabelle im Abschnitt «Nachrichtenaustausch»). Schreiben Sie Ihren Namen und den Namen des Empfängers / der Empfängerin in die entsprechenden Spalten.
8. Wiederholen Sie die Anweisungen ab Schritt 2 mit Ihrem zweiten Empfänger / ihrer zweiten Empfängerin. Falls Sie damit auch bereits fertig sind, wählen Sie noch beliebige weitere Personen aus.
</Steps>
</Restricted>

<Restricted id="7b947356-2a63-452b-8778-1c480adce7b7">
## Phase 3
Es sollten im Word-Dokument mindestens zwei verschlüsselte Nachrichten für Sie gepostet worden sein. 

<Steps>
1. Öffnen Sie wieder das [RSA Tool](https://www.devglan.com/online-tools/rsa-encryption-decryption) und gehen Sie zum Bereich __RSA Decryption__. Wählen Sie `Key type: Private key` and `Padding: OAEP SHA-256` (sollte bereits voreingestellt sein).
2. Kopieren Sie Ihren **Private** Key ins Feld __Private / public key__.
3. Suchen Sie im Word-Dokument nach einer Nachricht, bei der Sie als **Empfänger:in** angegeben sind. Kopieren Sie die Nachricht ins Feld __Encrypted Text__.
4. Klicken Sie auf __Decrypt__. Notieren Sie sich die entschlüsselte Nachricht (inkl. Absender:in) oben im Notizen-Textfeld.
5. Wiederholen Sie die Anweisungen ab Schritt 4 für alle weiteren Nachrichten, bei denen Sie als Empfänger:in angegeben sind.
6. Wiederholen Sie die Schritte 4 und 5 auch mal für eine Nachricht, bei der Sie **nicht** als Empfänger:in angegeben sind (z.B. bei einer Nachricht, die Sie selbst versendet haben). Können Sie sie entschlüsseln?
</Steps>

Welche Nachrichten haben Sie erhalten? Was passiert, wenn Sie versuchen, eine Nachricht zu entschlüsseln, die nicht für Sie bestimmt ist? Notieren Sie Ihre Beobachtungen hier fest.

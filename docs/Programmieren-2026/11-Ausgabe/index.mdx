# Ausgabe
Bisher haben unsere Python-Programme nur eine Form der «Ausgabe» gekannt: Turtle-Zeichnungen. Jedes Programm hat eine Turtle-Zeichnung produziert. In «realen» Programmen arbeiten wir aber nicht mit der Turtle. Stattdessen werden Ergebnisse (z.B. von Berechnungen)  oft einfach als Text in der sogenannten **Kommandozeile** ausgegeben.

## Ausgabe mit `print()`
Mit dem Befehl `print()` geben wir etwas in der Kommandozeile aus. Was wir in die Klammern schreiben, wird ausgegeben:

```py live_py slim
print('Hallo, Welt!')
print('Ich lerne Python.')
```

Jeder `print()`-Befehl erzeugt eine **eigene Zeile** in der Ausgabe. Der Text in den Anführungszeichen ist ein String (Datentyp `str`), den Sie bereits aus dem Kapitel zu den [Datentypen](../09-Variablen-und-Datentypen/03-Datentypen/index.mdx) kennen.

:::info[Die Kommandozeile in Classrooms]
In vielen Programmierumgebungen gibt es ein separates Fenster für die Ausgabe, die sogenannte **Kommandozeile** (auch _Terminal_ oder _Konsole_ genannt). In Classrooms gibt es kein solches Fenster: Die Ausgabe erscheint direkt **unter dem Code-Editor**, sobald Sie das Programm ausführen.
:::

Wir können nicht nur fixen Text ausgeben, sondern auch die Werte von Variablen und die Ergebnisse von Berechnungen:

```py live_py slim
seite = 50
print(seite)
print('seite')
print(seite * 4)
```

Achten Sie auf den Unterschied zwischen Zeile 2 und Zeile 3:
- `print(seite)` **ohne** Anführungszeichen: Python liest den Wert der Variable `seite` und gibt `50` aus.
- `print('seite')` **mit** Anführungszeichen: Das ist ein String. Python gibt ihn genau so aus, wie er dasteht, also `seite`.

:::info[Programme ohne Turtle]
In diesem Kapitel arbeiten Sie oft nicht mit der Turtle. Wenn Sie keine Turtle-Befehle (z.B. `forward()`, `left()`, etc.) verwenden, dann müssen Sie auch kein `from turtle import *` (und kein `done()`) schreiben.
:::

## Mehrere Werte ausgeben
Oft möchten wir nicht einfach eine Zahl ausgeben, sondern auch dazuschreiben, was sie bedeutet. Dazu können wir `print()` **mehrere Werte** übergeben, getrennt durch **Kommas**:

```py live_py slim
note_1 = 5
note_2 = 4.5
note_3 = 5.5
schnitt = (note_1 + note_2 + note_3) / 3

print('Notenschnitt:', schnitt)
```

Python gibt die Werte nacheinander auf derselben Zeile aus und setzt dabei **automatisch einen Leerschlag** zwischen zwei Werte. Dabei dürfen wir Strings und Zahlen beliebig mischen.

## f-Strings
Mit Kommas kommen wir schon recht weit. Manchmal stört aber der automatische Leerschlag:

```py live_py slim
name = 'Snoopy'
print('Hallo,', name, '!')
```

Die Ausgabe ist `Hallo, Snoopy !`, mit einem unschönen Leerschlag vor dem Ausrufezeichen. Diesen Leerschlag bringen wir mit Kommas nicht weg: Python setzt ihn **immer** zwischen zwei Werte.

Die Lösung sind sogenannte **f-Strings** (für _**f**ormatted_). Ein f-String ist ein String mit einem **`f` vor dem ersten Anführungszeichen**. Innerhalb des f-Strings können wir mit **geschweiften Klammern** `{...}` Variablen einfügen:

```py live_py slim
name = 'Snoopy'
alter = 7
print(f'Hallo, {name}! Du bist {alter} Jahre alt.')
```

Beim Ausführen ersetzt Python jede geschweifte Klammer durch den Wert, der darin steht. Den Rest des Strings gibt es genau so aus, wie er dasteht, inklusive aller Leerschläge (und eben nur dieser). Ob die Werte Strings oder Zahlen sind, spielt keine Rolle.

In den geschweiften Klammern dürfen auch Berechnungen stehen:

```py live_py slim
alter = 7
print(f'In drei Jahren bist du {alter + 3} Jahre alt.')
```

:::warning[Das `f` nicht vergessen]
Ohne das `f` vor dem String ist es ein ganz normaler String, und die geschweiften Klammern werden einfach mit ausgegeben. Es gibt dabei **keine Fehlermeldung**:

```py live_py slim
name = 'Snoopy'
print('Hallo, {name}!')
```
:::

<Solution id="72ac7193-745b-42b9-a6de-d3fcb51aaa74">
  ```py live_py readonly slim
  from turtle import *
  from random import *

  shape('turtle')

  anzahl_ecken = randint(3, 12)
  seite = randint(30, 80)

  for i in range(anzahl_ecken):
      forward(seite)
      left(360 / anzahl_ecken)

  print(f'Gezeichnet: {anzahl_ecken}-Eck mit Seitenlänge {seite} Pixel')
  print(f'Umfang: {anzahl_ecken * seite} Pixel')

  done()
  ```
</Solution>

::::aufgabe[⭐️ Reiskörner auf dem Schachbrett]
<TaskState id="00512942-12c7-430b-b313-8f6a652ecfb6" />

Einer Legende nach durfte sich der Erfinder des Schachspiels von seinem König eine Belohnung wünschen. Er wünschte sich Reiskörner: Auf das erste Feld des Schachbretts sollte ein Korn gelegt werden, auf das zweite Feld zwei Körner, auf das dritte vier Körner, und so weiter. Auf jedes Feld also doppelt so viele Körner wie auf das vorherige. Ein Schachbrett hat 64 Felder.

Schreiben Sie ein Programm, das für jedes Feld ausgibt, wie viele Körner darauf liegen, und am Schluss die Gesamtzahl aller Körner:

```
Feld 1: 1 Körner
Feld 2: 2 Körner
Feld 3: 4 Körner
Feld 4: 8 Körner
...
Feld 64: 9223372036854775808 Körner
Total: 18446744073709551615 Körner
```

:::tip[Tipps]
- Verwenden Sie eine Variable `koerner` für die Anzahl Körner auf dem aktuellen Feld und eine Variable `total`, zu der Sie in jedem Schleifendurchlauf die Körner des aktuellen Felds dazuzählen.
- Oder sie gehen es mathematisch an: Das Feld $i$ enthält $2^{i-1}$ Körner, für $i=1...64$.
:::

```py live_py id=3686bec5-0f11-4ebb-baa4-683d567c2dfe
```

<Solution id="32ebea29-1585-42fa-8d7e-54687d88a6e1">
  ```py live_py readonly slim
  koerner = 1
  total = 0

  for i in range(64):
      print(f'Feld {i + 1}: {koerner} Körner')
      total = total + koerner
      koerner = koerner * 2

  print(f'Total: {total} Körner')
  ```

  Zum Vergleich: Ein Reiskorn wiegt etwa 0.02 Gramm. Alle Körner zusammen würden also über 360 Milliarden Tonnen wiegen, ein Vielfaches der weltweiten Reisernte eines Jahres.
</Solution>

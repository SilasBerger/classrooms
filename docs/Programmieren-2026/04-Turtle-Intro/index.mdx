# Turtle 🐢
Ein ganz einfaches Turtle-Programm sieht wie folgt aus:

```py live_py title=einfaches__turtle__programm.py
from turtle import *

shape('turtle')

done()
```

Die Turtle-Befehle sind im Modul `turtle` gespeichert. Jedes Turtle-Programm muss deshalb mit `from turtle import *` (Zeile 1).

Auf Zeile 3 legen wir fest, wie unsere Turtle aussehen soll.

Und zum Schluss brauchen wir noch den Befehl `done()` (Zeile 5), um zu sagen, dass unsere Turtle-Zeichnung fertig ist.

## Eine erste Zeichnung
Nun soll die Turtle auch mal etwas zeichnen... **Führen Sie dieses Programm aber vorerst noch nicht aus!**
```py live_py title=erste__turtle__zeichnung.py readonly
from turtle import *

shape('turtle')

forward(40)
right(90)
forward(40)
right(90)
forward(40)
right(90)
forward(40)
right(90)

done()
```

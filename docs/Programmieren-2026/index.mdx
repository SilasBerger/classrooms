**Algorithmen**
- Sie können für einen gegebenen Sachverhalt anhand der **zwei Bedingungen** (Schritt-für-Schritt-Anleitung, löst eine Aufgabe oder ein Problem) entscheiden, ob es sich um einen Algorithmus handelt, und Ihre Entscheidung begründen.
- Sie können einen gegebenen Algorithmus auf die sechs **Anforderungen** (Allgemeinheit, Eindeutigkeit, Ausführbarkeit, Endlichkeit, Korrektheit und Determiniertheit) untersuchen und Ihre Entscheidung (bei Bedarf unter entsprechenden Annahmen) begründen.
- Sie können erklären, welche Anforderungen für einen brauchbaren Algorithmus immer erfüllt sein sollten und welche nicht zwingend notwendig sind.

**Python und Turtle**
- Sie können ein korrektes, lauffähiges **Turtle**-Programm erstellen, welches eine vorgegebene (**schwarz-weisse** oder **farbige**) Zeichnung erzeugt.
- Sie können **einfache** und **verschachtelte** `for`-Schleifen programmieren und diese **sinnvoll und korrekt** anwenden.
- Sie können den **Schleifenzähler** (Laufvariable) der `for`-Schleife in einem Programm anwenden und angeben, welche Werte er bei einem bestimmten `range()` annimmt (z.B. `range(4)` ➔ `i = 0, 1, 2, 3`).
- Sie können in einem Programm **Variablen** verwenden (Wert zuweisen, lesen, überschreiben) und für ein gegebenes Programm bestimmen, welche Variablen auf einer bestimmten Zeile aktuell im Arbeitsspeicher existieren und welche Werte sie haben.
- Sie können Variablen in Python gemäss den **Regeln und Konventionen** korrekt benennen und entsprechende Fehler erkennen und beheben.
- Sie können **arithmetische Ausdrücke** mit den Operatoren `+`, `-`, `*`, `/`, `//`, `%` und `**` von Hand auswerten und in einem Programm sinnvoll verwenden.
- Sie können für die drei **Datentypen** `int` (Integer), `float` und `str` (String) erklären, welcher Art von Daten sie entsprechen.
- Sie können diese drei Datentypen in einem Programm korrekt verwenden.
- Sie können in einem gegebenen Programm den Datentyp einer bestimmten Variable auf einer bestimmten Zeile herausfinden.

**Programmiersprachen, Compiler und Interpreter**
- Sie können die drei Bestandteile einer Sprache (**Vokabular**, **Syntax**, **Semantik**) erklären, Beispiele nennen und gegebene Beispiele dem entsprechenden Bestandteil zuordnen.
- Sie können natürliche und **formale Sprachen** unterscheiden und erklären, weshalb man zum Programmieren eine formale Sprache braucht.
- Sie können die Begriffe **Prozessor**, **Maschinensprache**, **Programmcode** und **Maschinencode** erklären.
- Sie können erklären, wie ein **Compiler** und ein **Interpreter** vorgehen, und die beiden hinsichtlich Geschwindigkeit, Weitergabe an andere Computer und Zeitpunkt der Fehlererkennung vergleichen.
- Sie können für ein gegebenes Programm begründen, ob sich eher eine kompilierte oder eine interpretierte Sprache eignet.
